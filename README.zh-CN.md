# MountMate / 挂载管家

[English](README.md)

MountMate 是一个 macOS 菜单栏工具：保持指定 SMB 共享连接，并按保护规则手动或每日清理临时挂载。打开应用会出现主窗口；关闭窗口后，菜单栏入口继续运行。

## 功能

- 将 SMB 共享设为“固定挂载”；启动、唤醒、网络恢复及定期检查时发现断线后重连。每个共享同一时间只发起一次连接，失败后逐步延长重试间隔。
- 概览扫描当前网络共享、磁盘镜像及外置磁盘；可以勾选当前 SMB 挂载，直接加入固定挂载。会带入地址和用户名，并跳过已添加的共享；U 盘、DMG 和其他协议只显示，不提供此项导入。
- 菜单栏图标有顺时针排列的 12 颗星，固定挂载占前面的星位。发现挂载时点亮，卸载或断开后熄灭；挂载数量超过 12 个时，额外的挂载不另增星位。
- 界面可跟随系统语言，也可选择简体中文、繁体中文、英语、西班牙语、法语、德语、日语、葡萄牙语（巴西）。
- 用户名保存在应用配置中，密码只保存在 macOS 钥匙串。认证失败会停止自动重试，直到用户重新连接或更新凭据。自动连接不弹出反复输入密码的对话框。
- 展示当前网络共享、磁盘镜像、可移除 USB 卷和其他外置盘；支持单独卸载、勾选多个卸载和按类别清理。
- 保护名单优先于一键及每日清理。保持连接的 NAS 始终受保护；手动断开会暂停自动重连。
- 每日按 Mac 本地时间清理一次，默认关闭、时间为 03:00。睡眠或应用未运行而错过时不补执行；不会主动唤醒 Mac。
- 清理只请求正常卸载，不强制弹出或关闭正在使用磁盘的程序。操作结果保留在应用内的最近运行记录中。

## 系统要求

Apple Silicon Mac，macOS 14 或更新版本。自行构建需要 Xcode 和 Swift。MountMate 在程序坞和菜单栏都有入口。
程序坞图标使用小型挂载图形与环绕的星星；菜单栏星星随挂载状态变化。

## 安装

从 [v0.3.2 预览版](https://github.com/xiaohardy/MountMate/releases/tag/v0.3.2)下载 Apple Silicon DMG。打开后，将 `MountMate.app` 拖到镜像内的 `Applications` 快捷方式，再从“应用程序”启动。主窗口“概览”中可以直接扫描并选择当前的 SMB 挂载，也可以手动添加共享；关闭主窗口后，可以从菜单栏重新打开。

### 首次打开时的 macOS 安全提示

这个预览版使用本机临时签名，**尚未经过 Apple 公证**。从 GitHub 下载后，macOS 可能阻止首次打开。只有在确认 DMG 来自[本项目发布页](https://github.com/xiaohardy/MountMate/releases/tag/v0.3.2)，并且你信任它时，才继续：

1. 尝试打开应用一次。如果出现拦截提示，选择“完成”（如有）。
2. 打开“系统设置 → 隐私与安全性”，在“安全性”中点“仍要打开”。
3. 系统再次询问时点“打开”。详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

如果 macOS 提示 **“App 已损坏”**或**“将损坏您的电脑”**，先停止使用，并在 [Issues](https://github.com/xiaohardy/MountMate/issues)反馈；不要关闭整个系统的安全检查。

当前预览版在 Apple Silicon、macOS 27 上构建和检查；macOS 14 是最低目标，较早版本与 Intel Mac 尚未实测。

## 构建与运行

```sh
swift test --scratch-path "${TMPDIR:-/tmp}/mountmate-test-build" --disable-sandbox
./scripts/package-dmg.sh
```

构建脚本生成 Apple Silicon DMG。图标由 `scripts/draw-icon.swift` 绘制，可用 `scripts/create-icon.sh` 重新生成。构建不需要连接 NAS。

第一次连接局域网 NAS 时，macOS 可能要求允许本地网络访问。要在登录后持续重连，请在主窗口的“固定挂载”页开启“登录时启动 MountMate”。语言切换位于“概览”顶部。

## 使用说明

1. 打开 MountMate，在“概览”点击“从当前挂载添加”，扫描并勾选 SMB 共享；也可点击“添加共享”，填写 `smb://服务器/共享名称`、账号和密码。不要在地址中写密码。
2. 在主窗口查看共享状态。手动选择“断开并暂停”后，可用“恢复连接”重新开启。菜单栏提供快速打开、添加、刷新和清理入口。
3. 在“清理规则”中选择参与清理的类别。默认只勾选磁盘镜像和明确标记为可移除介质的 USB 卷；其他外置盘与网络共享默认不清理。
4. 在当前挂载列表点击“保护”按钮，将挂载排除在“清理临时挂载”和每日清理之外；“取消保护”可恢复清理。“卸载”是手动安全卸载，不受保护名单限制。点击“清理临时挂载”执行一次；若需每日执行，再开启定时开关并在“清理规则”中以 `小时:分钟` 设置时间。

## 数据与限制

配置及最近 150 条运行记录位于 `~/Library/Application Support/MountMate/settings.json`；其中没有密码。删除共享配置时会一并删除该共享在应用钥匙串中的密码。从当前挂载导入时，MountMate 会先尝试使用 macOS 已保存的 SMB 凭据；如果系统未向应用提供可用凭据，状态会提示需要账号或密码，可编辑该固定挂载并将密码存入应用钥匙串。

当前自动挂载只支持 SMB。清理前会重新核对挂载来源，并排除系统盘及无法可靠识别的本地卷。普通卸载只卸载目标卷；对 U 盘不执行整个物理磁盘的强制弹出。网络共享虽仍显示为已挂载，但访问探测超时时会标记“连接异常”，不会擅自强制卸载重挂。应用只恢复挂载，不恢复因断线而失败的文件复制或其他任务。

MountMate 不包含分析统计或数据上传服务，只连接你配置的 SMB 服务器，并通过 macOS 接口检查或卸载挂载。发现问题或有改进建议，请到 [GitHub Issues](https://github.com/xiaohardy/MountMate/issues)反馈。源码按 [MIT 许可证](LICENSE)发布。
